# test-repo

This repository contains a simple example of analyzing a tennis dataset using Python.

## Quick start

1. Ensure you have Python 3.11+ installed. The script uses only the Python standard library.
2. Run the analysis script (a small sample dataset is included):

```bash
python3 analyze_tennis_dataset.py
```

You can also provide your own CSV dataset as an argument:

```bash
python3 analyze_tennis_dataset.py path/to/your_dataset.csv
```

The CSV file is expected to have the following columns:
`match_id`, `date`, `player1`, `player2`, `winner`.
